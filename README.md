# KothPlugin — Paper 1.21.4 y 1.21.11

Este proyecto genera dos compilaciones independientes usando Java 21:
- `KothPlugin-1.0.0-paper-1.21.4.jar`
- `KothPlugin-1.0.0-paper-1.21.11.jar`

## Cómo generar los JAR
1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. Abre la pestaña **Actions**.
3. Ejecuta **Build KothPlugin for Paper** o haz un push.
4. Descarga los artefactos `KothPlugin-Paper-1.21.4` y `KothPlugin-Paper-1.21.11`.

## Instalar
Usa el JAR correspondiente a la versión de Paper de tu servidor. Requiere Java 21. Copia el JAR a `plugins/` y reinicia el servidor.

Vault y PlaceholderAPI son dependencias opcionales según las funciones que utilices.

Nota: las dos variantes están configuradas para compilar; aún deben compilarse y probarse en servidores reales antes de considerarlas verificadas.
